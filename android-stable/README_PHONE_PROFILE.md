# Dedicated Android 10 home-phone profile

Target device: LG G7 ThinQ (LM-G710EMW), Android 10 / API 29.

The application remains compatible with API 29 while compiling/targeting API 35. It treats ordinary home Wi-Fi as dynamic unless the observed public IP matches the whitelisted Groww IP. It must auto-disarm new entries when the public IP changes, while continuing to protect already-filled strategies.
